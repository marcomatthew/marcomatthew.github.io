# Marco Matthew — Architecture Portfolio

A responsive personal architecture portfolio for GitHub Pages.

## Publish
1. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder to the root of your repository.
2. Keep GitHub Pages set to `main` branch and `/ (root)`.
3. Open https://marcomatthew.github.io after publishing.

## Personalize
- Replace project images in `assets/` with your own JPG/PNG files and update image paths in `index.html`.
- Update profile, education, experience, skills, and contact details in `index.html`.
- Replace the sample email with your real email.
- The included project illustrations are placeholders, not your actual project renders.
